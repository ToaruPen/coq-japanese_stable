# Caves of Qud 1.0.5 Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update QudJP's runtime patch contracts and verification evidence so the mod works against Caves of Qud 1.0.5 / Assembly-CSharp 2.0.211.50.

**Architecture:** Keep the existing Harmony patch boundaries and adapt only contracts changed by 1.0.5. Replace the `ReadSaveJson` result task with a completion-aware proxy, patch async popup producers at state-machine `MoveNext` boundaries, map generated state-machine methods back to logical owner keys, and resolve the callback-bearing `ShowYesNo` overload exactly. Preserve 1.0.4 scanner inventory provenance, deploy a dev build, and leave the GUI runtime smoke to the user.

**Tech Stack:** C# 13 / .NET 10 tests, Harmony 2.4.2, NUnit 4, QudTest headless fixtures, `just`, Caves of Qud 1.0.5 game assemblies.

### Task 1: Adapt save metadata translation to task completion

- [x] **Step 1: Write failing completion-contract tests**

Extend `SavesApiReadSaveJsonTranslationPatchTests` with an async dummy `ReadSaveJson` returning `Task<DummySaveGameInfo?>`. Patch it with the production postfix and assert that the returned proxy remains incomplete until the source completes, successful completion translates `Size`, successful null stays null, a translation callback exception leaves the healthy result successful, all fault exceptions remain present, and a canceled source remains canceled with its cancellation token.

The core test shape is:

```csharp
var completion = new TaskCompletionSource<DummySaveGameInfo?>(
    TaskCreationOptions.RunContinuationsAsynchronously);
var adapted = SavesApiReadSaveJsonTranslationPatch.AdaptCompletion(
    completion.Task,
    static result => SavesApiReadSaveJsonTranslationPatch.TranslateResult(result));

Assert.That(adapted.IsCompleted, Is.False);
completion.SetResult(new DummySaveGameInfo { Size = "Total size: 12mb" });
var result = await adapted;
Assert.That(result!.Size, Is.EqualTo("合計サイズ：12mb"));
```

- [x] **Step 2: Run the focused tests and verify RED**

Run:

```bash
dotnet test Mods/QudJP/Assemblies/QudJP.Tests/QudJP.Tests.csproj --filter 'FullyQualifiedName~SavesApiReadSaveJsonTranslationPatchTests'
```

Expected: compilation or assertion failure because the postfix still accepts `object` and translates before `Task<SaveGameInfo>` completion.

- [x] **Step 3: Implement the completion adapter and exact postfix**

Change the production postfix contract to:

```csharp
public static void Postfix(ref Task<SaveGameInfo> __result)
{
    __result = AdaptCompletion(__result, TranslateResult);
}
```

Implement `AdaptCompletion<T>` with `ContinueWith(..., CancellationToken.None, TaskContinuationOptions.ExecuteSynchronously, TaskScheduler.Default).Unwrap()`. Only call the transform for `RanToCompletion`, catch and trace transform failures, and return the original completed task from the continuation so aggregate fault contents and cancellation state are preserved. Move the existing reflection-based `Size` mutation into `TranslateResult(object? result)` and keep observability emission only after a successful mutation.

- [x] **Step 4: Run the focused tests and verify GREEN**

Run the command from Step 2. Expected: all `SavesApiReadSaveJsonTranslationPatchTests` pass.
