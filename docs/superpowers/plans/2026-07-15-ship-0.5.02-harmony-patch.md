# QudJP 0.5.02 and Harmony Patch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release QudJP 0.5.02 for Caves of Qud 1.0.5 and publish a separate, reversible Harmony 2.4.2 Windows patch through GitHub Release and Steam Discussions.

**Architecture:** Keep `0Harmony.dll` outside the normal mod ZIP. A deterministic Python builder verifies the official Harmony Fat archive, extracts the net48 DLL, and packages it with tracked Windows install/restore assets; the tag workflow attaches both the mod and Harmony ZIPs to one draft GitHub Release. The PowerShell updater fails closed on unknown game DLLs and preserves a named, byte-verified backup.

**Tech Stack:** Python 3.12+, pytest, PowerShell 5.1, Windows CMD, GitHub Actions, GitHub CLI, steamcmd, Steam Community Discussions
