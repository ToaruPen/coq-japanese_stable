# Caves of Qud 1.0.5 Static Producer Reconciliation

Date: 2026-08-15

## Scope

This report reconciles QudJP's tracked `EmitMessage`, `Popup.Show*`, and
`AddPlayerMessage` producer inventory against the local decompiled Caves of Qud
1.0.5 source. It records the player-visible gaps closed during the migration
without treating an empty static owner queue as project-wide untranslated-zero
proof.
