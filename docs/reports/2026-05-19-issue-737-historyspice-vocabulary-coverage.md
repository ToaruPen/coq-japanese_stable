# Issue 737 HistorySpice Vocabulary Coverage

Date: 2026-05-19

## Scope

This report tracks the direct dictionary-key coverage dimension added to Issue
#737. It is independent from route ownership: a route may call the intended
translator and still emit English when the selected `HistorySpice.json` leaf has
no QudJP component coverage or data-source reconstruction path.

QudJP does not ship a `Base/HistorySpice.json` override. The source vocabulary
remains the base game file, and QudJP currently translates selected outputs or
components through owner routes and dictionary lookup.

## Reproduction

```bash
uv run python scripts/historyspice_vocabulary_coverage.py \
  "$HOME/Library/Application Support/Steam/steamapps/common/Caves of Qud/CoQ.app/Contents/Resources/Data/StreamingAssets/Base/HistorySpice.json"
```

- `Mods/QudJP/Localization/Dictionaries/Scoped/historyspice-common.ja.json`
- `Mods/QudJP/Localization/Dictionaries/world-gospels.ja.json`

## Missing Leaf Classification

These examples are generated by the coverage script from missing direct keys in
all QudJP JSON dictionaries. They classify the missing vocabulary by
`HistorySpice.json` path group; they are not recommendations to add whole
generated phrase leaves.

This report intentionally counts direct dictionary keys, not regex pattern
routes. For example, `spice.cooking.ate[0]` / `You eat the meal.` appears as a
missing direct key, but the runtime popup route is already covered by the
anchored `^You eat the meal\.$` message pattern and `PopupShowTranslationPatch`
tests. That kind of route-owned coverage belongs in the HSE route audit, while
this report keeps the vocabulary dimension separate.

| Group | Representative missing leaves |
| --- | --- |
| Cooking ingredients / frames | Frame and quantity leaves such as `You toss *ingredients* into a pot and stir.`, `a pinch of`, `some`, `a dash of`, `a smidgen of`, plus cookbook placeholders such as `$markovTitle` |
| Recipe-name components | `$JerkyDisplayName`, `$LimbDisplayName`, and route-local preposition leaves `with`, `inside of`, `on top of`, `in`, `over` |
| Items / relic words | Latin-like generated suffix leaves such as `icus`, `ica`, `acus`, `ucus`, `ocus`, `ecus`, `aca`, `eca`, `oca`, `uca`, `yca`, `ycus` |
| Element fragments | No remaining direct misses; `spice.elements.*` is covered at `423 / 423`. |
| Common phrases | `in`, `throughout`, `throughout the entirety of`, `through`, `around`, `*var* twin` |
| Instances / authored actions | `of *var* *var2*`, `under`, `inside`, `behind`, `in`, `early in`, `late in`, `sometime in`, `drowned in a lake of *liquid*` |
| Extradimensional terms/templates | Remaining direct misses are numeric cult-symbol leaves and route-local `symbolOrNot` connector choices. |
| Gossip/templates | `*f1* stole @item.a@item.name from *f2*.`, `*f1* repeatedly beat *f2* at dice.`, `*f1* impersonated a leader of *f2*.` |
| Proverbs/templates | `*SacredThing* cannot compare to *sacredThing*`, `plant seeds in *ArableLand* and reap *sacredThing*`, `*Activity* leads to *profaneThing*` |

Template-like leaves with placeholders such as `*ingredients*`, `*cult*`,
`*f1*`, and `@item.name` should be owned by the route that expands or displays
the final generated text. Direct dictionary coverage is appropriate for stable
component leaves; route translators should reconstruct visible templates from
captures so selected components can be translated without overfitting a single
observed runtime phrase.

## Closure Implication

The next route-closure pass should classify missing leaves before adding
coverage. High-priority visible groups are cooking terrain and ingredients,
recipe-name components, element/common-phrase fragments used by annals and
journal text, items/relic words, instances, and extradimensional terms.

Vocabulary additions should be made in meaningful implementation units:
producer route, patch surface, `HistorySpice.json` family, or another semantic
component group that can be tested as a unit. Avoid incremental one-leaf
additions unless the leaf is a proven stable fixed literal and the surrounding
family is already owned or intentionally out of scope.

Do not add whole generated phrase leaves for runtime samples such as observed
campfire meals or sultan prose. Prefer scoped component dictionaries or
producer/data-source reconstruction, with tests that include at least one
non-observed variant.
